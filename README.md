# WaveStim-Crankshaft-Camshaft-Simulator
Professional Crankshaft/Camshaft (CKP/CMP) signal generator &amp; pattern builder based on Waveshare ESP32-S3-BOX. Features built-in Pattern Viewer with phase synchronization markers and FAT32 SD-card support. Универсальный имитатор сигналов ДПКВ/ДПРВ для диагностики и проверки ЭБУ «на столе».
